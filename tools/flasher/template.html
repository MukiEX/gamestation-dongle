Joy-Con 2 Dongle Tool

Flash the dongle firmware to an ESP32-S3 N16R8, then capture its log while you test. Works in Chrome, Edge or Opera on a desktop computer.

This browser can't reach USB serial ports. Open this file in Chrome, Edge or Opera on Windows, macOS, Linux or ChromeOS. If it still says this, serve the file locally (for example python -m http.server in its folder) and open http://localhost:8000.

How to use

      
Plug the dongle into a PC or console and pair your Joy-Con 2 (or Pro Controller 2) once: hold the small SYNC
        button on the controller's rail until it connects. From then on, any button wakes it and it reconnects by itself.
        A left and a right Joy-Con become one controller; a single Joy-Con works sideways on its own.
        The dongle starts as an Xbox 360 (XInput) controller; pick another type with the shortcuts below or in the configurator.

In the configurator (http://192.168.7.1) you can also set rumble strength, stick deadzone, button layout,
        what the Joy-Con mouse sensor does, and forget paired controllers. Your PC keeps its normal internet connection meanwhile.

    Motion viewer
    
      
    Reads the dongle's controller output in DS4, DualSense, Switch Pro or Steam Controller mode and decodes the gyro and accelerometer
        exactly the way SDL does (SDL's controller code comes from Steam's). If these readings match the configurator's Live input, the dongle's
        output is right; anything still odd in Steam is Steam's own handling.
    
      
    This browser can't read USB controllers (WebHID). Open this file in Chrome or Edge.

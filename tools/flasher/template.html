Joy-Con 2 Dongle Flasher

Writes the dongle firmware to an ESP32-S3 N16R8 over USB, from this page. Works in Chrome, Edge or Opera on a desktop computer.

This browser can't reach USB serial ports. Open this file in Chrome, Edge or Opera on Windows, macOS, Linux or ChromeOS. If it still says this, serve the file locally (for example python -m http.server in its folder) and open http://localhost:8000.

  1. 1

    Put the board in download mode

    Hold BOOT, plug the board's USB (OTG) port into this computer, then release BOOT. Using the board's UART/COM port instead works without BOOT.

  2. 2

    Connect

    Pick the board in the browser's port list. In download mode it shows up as USB JTAG/serial debug unit (or as the UART chip's name).

    Loading flasher library…
  3. 3

    Flash

    Takes about 15 seconds at 921600 baud. Don't unplug the board until it says done.

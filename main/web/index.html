Output

What the PC or console sees. Takes effect when you exit.
On: the dongle is only the controller, as consoles insist. No log port and no USB mouse, so mouse targets below do nothing; XInput uses the real Xbox 360 ID (045E:028E). Off: the controller plus the log port and, when something below goes to the mouse, a USB mouse. Takes effect when you exit.
The serial port next to the controller (only with single controller mode off).
Hold Select and Start for 3 s: next controller type. Hold Credit and Home for 3 s: this page (needs Credit on Capture, the default).

Display

The dongle's own screen. 0 turns it off. Applies live.
Landscape: the stick lies flat. Upright: it stands (e.g. plugged facing down into a dock). ↻ turns the picture round. Applies live.

Paddle

How much output each of the knob's 81 steps per turn is worth. 1× = one step (one JP3 count, one wheel notch, 8 mouse pixels).
Knob position modes: steps from centre to full deflection (81 = a full turn each way). The stick stays at the end until you turn back.

Trackball

1× = one mouse pixel per trackball count; JP3 takes one step per 8 counts at 1×.

JP3 spinner output

On: pressing the pad's d-pad hands the two lines back to it (the encoder first steps back to rest, at most two steps), so menus work normally; turning the paddle or rolling the trackball takes them over again. Off: the encoder always owns them.
How long each encoder state (and each d-pad tap) is held. It has to outlast the host's polling, or steps are lost; 4 ms (250 steps a second) is safe for MiSTer and PCs. Faster turning than that queues up to 128 steps; beyond that they are dropped.

Keypad and extra buttons

The pad's other buttons map to their usual places: A, B, X, Y by position (A is the bottom button), L1 / R1 = L / R, L2 / R2 = ZL / ZR (triggers), Select = −, Start = +, Home = Home.
